# Fuze is a self-hosted Open Source project

Fuze is a non-commercial Open Source project intended to be installed and
operated by its users. The project author does not provide, and does not plan to
provide, a ready-to-use hosted Fuze service.

Each Fuze installation is an independent instance. Its owner/operator, not the
Fuze project author, decides who may use it, which optional providers are
enabled, where data is stored, how long it is retained, and how backups and
security are handled. The operator is therefore responsible for the instance's
privacy notice, applicable terms, provider compliance, and user requests.

Fuze can store account details, authentication sessions and access keys,
playlists, settings, provider configuration, and downloaded media. Users can
delete their own account and database-linked data from Settings. An operator may
also delete accounts through administration tools. Storage backups and external
object storage are controlled by the operator and may require separate cleanup
under that operator's retention policy.

Optional integrations with YouTube, Yandex Music, and Spotify connect to
independent services governed by their own terms. See the provider-specific
reviews in this directory. Enabling an integration does not grant rights to
content or waive the provider's rules.
